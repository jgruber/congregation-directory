Congregation Directory

A free web application for searching a congregation's member directory and scheduling follow-up.

Congregation Directory is a free, browser-based application that lets a congregation's administrators search and organize their member directory and, optionally, create Google Calendar events that invite the people they select. You import a Persons.csv export, and the application builds a private, local database you can search, filter by tags, view on a map, print contact sheets from, and analyze. All data stays on your own device — there is no server that stores your information.

Purpose: to give congregation secretaries and coordinators a fast, private way to look up members and organize scheduling — including creating a single Google Calendar event that invites the members currently displayed in the app.

What it does

  • Search & filter members by name, tags, appointments, age, and field service group.
  • Contact & share — email, message, export vCards, and print directory / address sheets.
  • Reports — statistics, demographics, capability coverage, and data-quality checks.
  • Schedule — optionally create a Google Calendar event that invites the people currently displayed.

How it uses Google

The optional “Add Google Calendar Event” feature signs you in with Google in your browser and creates a single calendar event that invites the people you have selected. It requests only:

  • calendar.events — to create the event and send the invitations you configure. It does not read or change your other events.
  • userinfo.email — to show which Google account is signed in.

Google data is processed only in your browser, is never sent to the developer, and is used solely to provide this feature, in adherence with the Google API Services User Data Policy, including its Limited Use requirements. See the Privacy Policy for details.

Who it's for

Congregation secretaries and coordinators who maintain a member directory and want a fast, private way to search it and organize follow-up — with no installation and no data leaving their device.
